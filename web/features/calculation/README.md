# Игровые результаты

`CalculationPanel.tsx` подключает селекторы к исходным игровым таблицам и вызывает domain/game-tables.ts без дублирования расчёта. Заряды ограничены реально доступными профилями; выбор 82 мм и M777 запоминается отдельно. `format.ts` форматирует числовые значения и названия снарядов. При недоступном решении старые числа скрываются; источник, диапазон, метод и ограничения доступны в раскрываемом блоке.

# Орудия и сессия

`state.ts` содержит чистый reducer сессии: 1–6 орудий, независимые A/B, выбор оружия и двух профилей, фильтры. Добавление копирует B и настройки, выключает область; удаление сохраняет номера, добавление занимает первый свободный. Имена и закладки общие. `Dialog.tsx` использует нативный модальный dialog с возвратом фокуса. Это состояние в памяти, ещё не формат импорта: преобразование в desktop FleetState и проверка файла относятся к этапу 8. Тесты: tests/fleet.test.mjs.

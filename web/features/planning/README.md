# Подбор позиции

`PlanningPanel.tsx` применяет три фильтра целыми числами в desktop-пределах, управляет видимостью и показывает точную оценку A. `usePlanning.ts` запускает модульный Web Worker: расчёт и построение дорожного индекса выполняются вне UI. Новые параметры завершают предыдущий worker; ответ дополнительно проверяется по ключу, а маска скрывается сразу при несовпадении ключа. Маска передаётся как transferable Uint8Array. Фильтры используют исходные сценарные точки, независимо от пользовательских названий, закладок и видимости дорог. Тест tests/planning-worker.test.mjs запускает production-worker через Node-мост и сверяет полный хеш маски с C#.

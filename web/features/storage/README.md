# Локальное хранение

`codec.ts` проверяет настольный FleetState/Session, миграцию имён, профили, координаты, общие поля и размер. `database.ts` выполняет сравнение и запись в одной IndexedDB-транзакции. `session-store.ts` управляет очередью, статусом, резервной копией и конфликтами; React читает его через useSyncExternalStore. `StoragePanel.tsx` содержит импорт с предварительным просмотром, экспорт и восстановление. `preferences.ts` проверяет отдельные настройки отображения. Проверки формата и хранения: tests/storage.test.mjs; сквозной браузерный сценарий: scripts/verify-storage-browser.mjs.

# Карта

Canvas-отрисовка, управление камерой, слоями и маркерами. `MapWorkspace` хранит временное состояние интерфейса; `MapCanvas` обрабатывает события и размеры; `renderer.ts` рисует исходную игровую геометрию. `camera.ts`, `geometry.ts` и `tile-cache.ts` тестируются независимо от React. Данные адресуются через ../resources/catalog.ts. Чтение напрямую из папок вне web запрещено конфигурацией dev-сервера.

Геометрия остаётся в игровых X/Z. Начало нумерации тайлов — северо-запад; размер полезной части 1024×1024, полный PNG 1026×1026 с рамкой 1 пиксель. Рамка обрезается при отрисовке. Тайлы нужны при масштабе от 0.5 px/м, здания — от 0.3 px/м. Кеш ограничен 24 изображениями и четырьмя запросами, отменяет устаревшие запросы и освобождает ImageBitmap. При ошибке остаётся обзорная подложка; повтор выполняется кнопкой. `MapScene` поддерживает дополнительные маркеры и маску для подключения на следующем этапе. Пользовательское хранилище здесь не реализовано.

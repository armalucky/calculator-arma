# LuckyMap Web: разработка

Инструкции запуска, сборки, хостинга и лицензирования находятся в [главном README](../README.md).

## Структура

- `app/` — оболочка интерфейса и оформление.
- `domain/` — игровые таблицы, координаты, дороги и подбор позиции.
- `features/` — карта, орудия, расчёты, Worker, ресурсы и локальное хранение.
- `scripts/prepare-resources.mjs` — подготовка 109 разрешённых ресурсов из корневых data/references/LICENSE; исходники не меняются.
- `tests/` — проверки приложения и зафиксированные эталонные данные.
- `public/resources/` и `dist/` — генерируются, исключены из Git.

## Проверки

Из этой папки: `npm run check`, `npm test`, `npm run build`.

Тесты сравнивают реализацию с сохранёнными результатами исходного игрового приложения: 2408 расчётов, 31 профиль, 42 случая координат, 166 дорожных расстояний, 388 оценок позиции и 8 полных масок. Для запуска не нужны C#-исходники, .NET или Windows. Хеши исходного C# в `tests/fixtures/domain-reference.json` сохраняются как сведения о происхождении эталона; актуальные хеши игровых данных проверяются тестами. При изменении таблиц необходимо отдельно пересмотреть эталон, не подменять его результатами тестируемой реализации.

При работающем сервере `npm run verify:delivery -- http://127.0.0.1:4173/` проверяет загрузку и SHA-256 всех ресурсов. `npm run verify:storage-browser` проверяет сохранение, импорт/экспорт и конфликты вкладок в отдельном профиле Chrome.

`npm run verify:release` запускает собственный статический сервер и проверяет сборку в корне и подпапке, включая Worker и сохранение. Нужен Chrome; путь можно задать через CHROME_PATH. Edge проверяется при наличии, путь задаётся через EDGE_PATH. `npm run package:release` — дополнительная Windows PowerShell-команда упаковки уже проверенной веб-сборки в ZIP; она не собирает настольную программу. На других системах можно публиковать содержимое dist непосредственно.

## Ресурсы и сохранения

Имена ресурсов включают SHA-256. Карта подгружает видимые тайлы: до четырёх запросов одновременно и до 24 декодированных изображений в кеше. `desktop-background.jpg` — историческое имя используемого веб-картой изображения, не исполняемый файл.

IndexedDB хранит сессию, localStorage — отображение. JSON поддерживает формат прежних сохранений для переноса данных. Подпапки одного origin используют общую базу. Предусмотрены восстановление резервной копии, выгрузка повреждённых данных и явное разрешение конфликта вкладок. Service Worker и облачный сервер не используются.

# Этап 6 — интерактивная игровая карта

Реализована отдельная веб-карта LuckyMap для Arma Reforger. Desktop-исходники, EXE и пользовательские сохранения не изменялись.

## Доступно

- Обзорная подложка и детальные тайлы; векторные дороги и здания, сетка, названия.
- Масштабирование вокруг курсора колесом, кнопки масштаба, перемещение мышью. Стрелки и Home работают при фокусе карты; Ctrl+колесо оставлено браузеру.
- Режимы обзора, выбора A и B; маркеры, соединяющая линия, расстояние и координаты курсора.
- Ввод X/Z или клетки, проверка ошибок, показ обеих точек, сброс, выбор точки сценария.
- RU/EN без сброса точек и камеры; прокручиваемая панель при уменьшении окна.
- Состояния загрузки, ошибки обязательных данных и повтор. Ошибка тайла оставляет подложку, сообщение не меняет размер карты.

Камера использует формулы `MapCanvas` из `app/MapApp.cs`: X направлен вправо, Z вверх, центр карты 5120/5120. Canvas учитывает devicePixelRatio; игровые координаты не зависят от разрешения экрана. Геометрия переносится без упрощения: 9426 дорожных четырёхугольников и 9626 зданий. При отрисовке тайлов обрезается однопиксельная рамка, сохраняется северо-западная нумерация.

Детализация загружается только для видимой области при масштабе от 0.5 px/м. Одновременно выполняется до четырёх запросов; кеш хранит до 24 декодированных изображений. При очень большом окне приоритет у центральных тайлов, остальное покрывает обзор. Устаревшие запросы отменяются, вытесненные ImageBitmap закрываются. Ошибка не вызывает бесконечных повторов при перерисовке.

## Проверки 09.09.2026

`npm test`: 23 группы, включая пять новых проверок карты — обратимость координат, якорь масштаба, рамка A/B, тайлы по краям карты, сохранность всех вершин, ограничения кеша, отмена с поздним ответом, освобождение изображений и повтор после ошибки. Существующие сравнения вычислительного ядра с C# также проходят. `npm run check` и production-сборка проходят.

В отдельном Headless Chrome 152 проверено:

- Ввод координат, выбор A/B мышью и отображение линии между ними.
- Независимая контрольная точка здания Gym из desktop-проверки: X=4723.68, Z=5218.409. При включённом слое центральный пиксель имеет цвет здания (182,188,178); при выключенном видна подложка. Детализация проверена визуально.
- Масштабирование с сохранением координаты под курсором; смена RU/EN и размера окна сохраняет точки и камеру.
- Размеры окна 1440×960, 1180×800 и 760×800; горизонтального переполнения нет, в узком окне панель прокручивается.
- Искусственный отказ PNG: предупреждение, обзорная подложка, успешное восстановление кнопкой повтора. Отказ файла дорог: экран ошибки обязательных данных.

Скриншоты локальной проверки находятся в игнорируемой папке `web/work/`. Эти проверки не заменяют будущую приёмку в Edge/Firefox, отдельную проверку масштаба браузера 125% и полного рабочего сценария.

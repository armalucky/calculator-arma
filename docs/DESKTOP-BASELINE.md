## Контрольная копия

Локальная папка: `dist/desktop-baseline-2026-09-09/` (исключена из Git).

- `source.zip` — все отслеживаемые файлы исходного коммита, включая подготовленные ресурсы.
- `LuckyMap.exe`, `BakhmutMap.exe` — копии существовавших до проверки программ.
- `protected-files.json` — локальный список SHA-256 исходных файлов, программ и существующих файлов пользовательских данных; не публиковать.
- `checkout/` — извлечённая копия исходников для независимой сборки и тестирования.
- `build-lucky.log`, `build-classic.log`, `verify-*.log`, `package.log`, `test-results.json` — результаты проверки.

Пользовательские сохранения не включены в архив исходников и не переносились в тестовую копию. Их исходные файлы остались на месте; неизменность проверена по хешам. Контрольная папка локальная: для резервного хранения её следует скопировать отдельно. Сам коммит позволяет восстановить отслеживаемые исходники, но не локальные EXE и сохранения.

## Условия дальнейшей работы

1. Добавлять веб-приложение отдельно в `web/`.
2. Сохранять исходники, сборку и выпуск обеих Windows-версий.
3. Не изменять пользовательские сохранения при разработке и проверке веб-версии.
4. Проверять общие ресурсы на совместимость с Windows при их изменении.
5. Перед завершением переноса повторить проверки LuckyMap и переносимого пакета.

Для восстановления контрольных исходников можно извлечь `source.zip` в новую папку либо создать отдельную копию указанного коммита. Сохранённые EXE находятся рядом с архивом; ресурсы для запуска находятся внутри архива. Это позволяет восстановить контрольную версию без перезаписи текущей работы.

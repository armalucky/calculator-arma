LuckyMap — Windows portable application / Портативное приложение

ENGLISH
1. Extract the entire ZIP to a writable folder. Do not run it inside the ZIP.
2. Open the extracted LuckyMap folder and run LuckyMap.exe.
Keep the data and references folders beside the executable.
No installation, Python or source-code build is needed to run this package.
Requires Windows with .NET Framework. This is a Windows Forms desktop application.

F11 or the top-right button: fullscreen / windowed mode.
Esc: return to windowed mode. Alt+F4: close the application.
Choose Russian or English at the top right. Ctrl+S saves all guns.
Your positions and preferences are created in user-data beside the executable.
For an update, keep a copy of your old user-data folder and transfer it to the
new extracted folder. This download contains no personal saves or preferences.

Game-table calculations do not model terrain elevation, wind, obstacles or
smoke activation. Match your weapon, shell and charge to the game.

РУССКИЙ
1. Полностью распакуйте ZIP в папку, доступную для записи. Не запускайте из архива.
2. Откройте распакованную папку LuckyMap и запустите LuckyMap.exe.
Папки data и references должны оставаться рядом с приложением.
Установка, Python и самостоятельная сборка для этого пакета не нужны.
Требуется Windows с .NET Framework.

F11 или кнопка справа сверху: полноэкранный / оконный режим.
Esc: вернуться в окно. Alt+F4: закрыть приложение.
Язык переключается справа сверху. Ctrl+S сохраняет все орудия.
Сохранения и настройки создаются в папке user-data рядом с приложением.
При обновлении сохраните старую папку user-data и перенесите её в новую
распакованную папку. Архив не содержит чужих сохранений и настроек.

Расчёты по игровым таблицам не учитывают высоты, ветер, препятствия и момент
срабатывания дыма. Оружие, снаряд и заряд должны соответствовать выбранным в игре.

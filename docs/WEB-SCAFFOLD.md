# Шаг 3: самостоятельный веб-проект

Дата: 2026-09-09. Основа требований: [WEB-FEATURE-PARITY.md](WEB-FEATURE-PARITY.md).

## Выполнено

- Создана независимая папка `web/` с React, TypeScript и Vite, строгой проверкой типов и lint.
- Настроены `npm run dev`, `check`, `build`, `preview`; зависимости закреплены lockfile.
- Исходный шаблон Sites адаптирован к статическому клиентскому приложению. Удалены серверные зависимости и неиспользуемые демонстрационные компоненты.
- Добавлена стартовая страница в палитре LuckyMap с работающим переключателем RU/EN. Она явно сообщает, что функции калькулятора ещё не подключены.
- Выделены папки для предметной логики, карты, орудий, расчётов, подбора, хранения и локализации. Будущие модули пока обозначены README, без фиктивной реализации.
- Настроены относительные пути сборки для размещения в подпапке. Веб-сервер ограничен папкой web и адресом loopback.
- Написана [инструкция запуска](../web/README.md).

## Проверки

Среда: Windows, Node.js 24.13.1, npm 11.8.0, Vite 8.2.2.

| Проверка | Результат |
|---|---|
| Установка npm и запись lockfile | Успешно; итоговая проверка зависимостей сообщает 0 известных уязвимостей |
| `npm run check` | TypeScript и oxlint без ошибок |
| `npm run build` | Успешная статическая сборка `web/dist` |
| `npm run dev` | Запуск на `http://127.0.0.1:5173/` |
| HTTP-загрузка dev-страницы, main.tsx, page.tsx, globals.css | Все ответы 200 |
| Запрос корневого README через dev `/@fs/` | Ответ 403: доступ вне web запрещён |
| `npm run preview` | Готовая сборка раздаётся на `http://127.0.0.1:4173/` |
| HTML, JS и CSS готовой сборки | Все ответы 200, ссылки на JS/CSS относительные |
| SHA-256 контрольного списка Windows | Все 274 файла неизменны |
| `git diff --check` | Без ошибок |

Стартовая сборка состоит из HTML, CSS и JS, суммарно около 211 КБ без сжатия. В неё не включены карта, пользовательские данные или Windows EXE. Передана команда открытия preview в панели Codex; приложение вернуло статус queued. Автоматическая проверка кликов и визуальная проверка браузера на этом шаге не выполнялись. Отдельное развёртывание в подпапке также ещё не проверялось: здесь проверены относительные пути собранных ресурсов.

При установке исходный шаблон содержал Vite 8.0.13 с замечанием npm audit для Windows. Применена исправленная версия 8.2.2; после повторной установки замечаний нет. Неиспользуемые компоненты исходного шаблона, не проходившие его lint, удалены; правила lint не ослаблялись.

## Границы результата

Этот шаг не реализует карту, расчёты, сессии, автосохранение или импорт/экспорт. Выбор языка пока живёт в памяти до перезагрузки. Домен, хостинг и GitHub-публикация не настроены. ПК-программы и исходные данные не изменялись; повторная сборка Windows не требовалась.

Следующий шаг — выборочная подготовка общих данных и ресурсов карты для веб-сборки, с сохранением исходных таблиц как единого источника.

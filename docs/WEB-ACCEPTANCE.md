# Этап 9: приёмка статической сборки

Дата: 2026-09-09. Сборка подготовлена к размещению; внешняя публикация ещё не выполнена.

## Результаты

- TypeScript и lint проходят; все 38 групп тестов проходят без пропусков. Включены сравнения с C# для 31 игрового профиля и восьми полных масок.
- Одна и та же production-сборка проверена в Chrome 152.0.7977.77 по адресам `/` и `/luckymap/`, а также в Edge 152.0.4191.66 по `/luckymap/`. Использовался отдельный статический HTTP-сервер без Vite и без подстановки index.html вместо отсутствующих ресурсов.
- Для обоих путей проверены HTTP, длина и SHA-256 всех 109 логических ресурсов. Состав сборки: 112 физических файлов, 53 581 125 байт. Некоторые одинаковые ресурсы используют один файл с общим хешем.
- Во всех трёх браузерных прогонах проверены лимит шести орудий, отдельные настройки, закладка, язык/слои/камера и перезагрузка. Настоящий Worker построил 5909 ячеек для контрольной игровой сессии; выключение слоя удалило маску.
- Реальный скачанный JSON совпал с сессией; проверены выбор файла, отмена и подтверждение импорта, резервная копия и отказ при неверном JSON. Две реальные вкладки не перезаписывают изменения друг друга; имитированная ошибка квоты сохраняет данные до успешного повтора; повреждённая запись восстанавливается с сохранением исходника.
- В успешных прогонах нет необработанных исключений страницы и ответов HTTP с ошибками для ресурсов приложения. Стандартный необязательный запрос favicon исключён из этой проверки.
- Статический сервер возвращает 404 для исходников, package.json, .env, пользовательских сохранений и отсутствующих файлов. Проверка состава сборки допускает только bundles приложения и ресурсы из каталога.
- Итоговый снимок Edge визуально проверен при 1440×960. Проверки карты, управления и меньших размеров предыдущего этапа описаны в [WEB-INTERFACE.md](WEB-INTERFACE.md).
- Все 274 защищённых файла настольной версии совпали по SHA-256 с исходным состоянием; `git diff --check` проходит.

Firefox и Safari не проверены: локально не установлены. Проверка использует headless Chrome/Edge и отдельные временные профили; она не заменяет испытание на реальном публичном домене с настройками выбранного хостинга. Offline/PWA и облачная синхронизация не заявляются.

## Повторение

Из `web` после установки зависимостей:

```powershell
npm run check
npm test
npm run build
npm run verify:release
npm run package:release
```

Каждая команда должна завершиться успешно перед следующей. `verify:release` сам запускает и закрывает временный сервер на свободном порту; открытый preview на 4173 не затрагивается. `CHROME_PATH` и `EDGE_PATH` переопределяют пути к браузерам. Chrome обязателен, отсутствие Edge явно отражается в отчёте. Проверки не используют личные профили или сохранения.

Машиночитаемый отчёт со всеми хешами: `web/work/release-report.json`; отчёты браузеров, снимки и синтетические файлы: `web/work/storage-browser-*/`. Эти каталоги исключены из Git.

`package:release` требует успешного отчёта, сверяет с ним каждый файл текущей сборки, создаёт новый `dist/web-release-*/luckymap-web.zip` и повторно проверяет содержимое архива по SHA-256. Рядом находятся отчёт и `SHA256SUMS.txt`. Архив содержит index.html в корне, assets и resources; исходники и пользовательские данные не включены. После изменения сборки приёмку нужно повторить.

Архив этого прогона: `dist/web-release-20260909-172441-3de3bb9e/luckymap-web.zip`, 49 678 156 байт. SHA-256: `3d5468c19ba9cf756ec1b7c6c40c1fdf11e458d95d69011271a99bc7ce4803b7`.

# LuckyMap Web

Веб-карта и калькулятор игровых таблиц для **Arma Reforger**. Этот репозиторий содержит только веб-версию: React, TypeScript и Vite. Исполняемые файлы Windows и исходники настольного приложения сюда не входят.

**Разработчик — [Beld](https://steamcommunity.com/id/Beldherder/)** · [GitHub](https://github.com/kirsanovdmitriis-bit).

## Возможности

- Карта Bakhmut: масштабирование, дороги, здания и координатная сетка.
- До шести орудий с независимыми точками и игровыми профилями.
- Подбор позиции в Web Worker, общие закладки и переименование точек.
- Русский и английский интерфейс, полноэкранный режим.
- Автосохранение в браузере, импорт и экспорт JSON, резервная копия и защита от конфликта вкладок.

## Запуск

Установите Node.js 24, затем из корня репозитория выполните:

```sh
npm --prefix web ci
npm --prefix web run dev
```

Откройте http://127.0.0.1:5173/ . Для работы пользователю нужен браузер с JavaScript; EXE не требуется.

## Проверка и сборка

```sh
npm --prefix web run check
npm --prefix web test
npm --prefix web run build
npm --prefix web run preview
```

Готовый сайт находится в `web/dist`, просмотр сборки — http://127.0.0.1:4173/ . Открывать index.html через file:// не следует.

## Подключение хостинга к GitHub

- Репозиторий: `armalucky/calculator-arma`, ветка: `main`.
- Рабочая директория сборки: корень репозитория; Node.js: 24.
- Команда: `npm --prefix web ci && npm --prefix web run check && npm --prefix web test && npm --prefix web run build`.
- Публичная выходная папка: **`web/dist`**.
- Node.js нужен при сборке; сам сайт раздаётся как статические файлы через HTTPS.

Загружайте весь репозиторий: сборка использует `data`, обложку из `references` и LICENSE. Публикуйте только содержимое `web/dist`. Для подпапки используйте URL с завершающим `/`; сборка имеет относительные пути. Хостинг должен отдавать корректные MIME-типы для JS/CSS/JSON и 404 для отсутствующих ресурсов. После размещения: `npm --prefix web run verify:delivery -- https://example.com/luckymap/`.

Исходники на GitHub сами по себе не означают публикацию работающего сайта. Хостинг подключается отдельно.

## Данные пользователя

Сессия хранится в IndexedDB конкретного браузера; язык, слои и камера — в localStorage. Для перехода с локального адреса на публичный сайт или на другое устройство экспортируйте JSON и импортируйте его на новом адресе. Аккаунтов, облачной синхронизации и гарантированного офлайн-режима нет.
